# 토닥토닥 (todottodot)

작은 자기돌봄 미션으로 자존감을 키우고, 나를 닮은 **레트로 픽셀 캐릭터**가 함께 성장하는 앱 프로토타입.
구석에 쪼그려 앉아 있던 캐릭터가 방을 치우고, 창문을 열고, 결국 사람들과 함께 밖으로 나가요.

- 기본 언어 한국어 / 영어 전환 지원 (`js/i18n.js`)
- 성별 선택 없는 포용적 캐릭터 커스터마이징
- 기획·디자인 문서: [docs/DESIGN.md](docs/DESIGN.md)

## 실행
빌드 과정 없이 `index.html`을 브라우저로 열면 됩니다. (카메라 거울 기능은 `https://` 또는 `localhost`에서 동작)

```bash
python3 -m http.server 8000
```

`나` 탭의 **데모: 레벨 미리보기** 슬라이더로 Lv1~10 장면 변화를 바로 볼 수 있어요.

## 구조
- `js/sprites.js` — 픽셀 캐릭터/장면 렌더러 (이미지 없이 코드로 그림)
- `js/app.js` — 화면, 미션, 레벨, 저장(localStorage)
- `js/i18n.js` — 한국어/영어 문자열
- `assets/fonts` — Galmuri11 픽셀 폰트 (SIL OFL 1.1)
